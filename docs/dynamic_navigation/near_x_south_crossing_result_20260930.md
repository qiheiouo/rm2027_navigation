# 南侧出发的独立 `x` 轴近场穿越结果（2026-09-30）

## 结论

预登记的相反观察侧试次再次出现**原噪声 batch 300/2000 没有联合安全候选、扩大噪声后才出现安全候选，而原 V1 硬项仍全体打平**。这支持北侧周期 73 的采样覆盖与硬评分饱和并非该侧别独有，但仍是同一已知箱体的两个输入，不等于跨场景稳定性。此试次原生七项总分在捕获 300 条中有 2 条未精确重放，最大差 `0.257` 分；静态碰撞标记完全一致。依既定门槛，**不对相反侧的安全候选综合名次或最终聚合给出结论**，也没有改运行参数。
