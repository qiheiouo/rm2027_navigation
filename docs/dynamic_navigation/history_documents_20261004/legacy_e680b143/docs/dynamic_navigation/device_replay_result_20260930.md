## 限制

同包版本不是同镜像/二进制；已知未定义读取无法要求稳定跨设备数值。

本项提供迁移否定证据和差异定位，不给出动态安全或算法有效结论。
原 capture、旧 evidence、数值门及失败 summary 均保留。
