# 滤波候选评分与控制聚合表述对照

状态：**统一聚合表述没有消除目标附近的推进损失；三个预选周期的两种输出均通过原静态图及 0.05 m 动态门。** 本轮只比较[跨周期七项原生评分](filtered_cross_cycle_native_20260928.md)后，同一组权重如何聚合控制，不改变 V1、七项标准 critic、MPPI 正则、温度、采样、footprint、padding 或安全门，也没有启动新的闭环试次。

[对照脚本](../../experiments/dynamic_prediction_v1/frozen_cycle/filtered_aggregate_alignment_probe.py)固定周期 147、162、263 各 300 条采样、前四周期滤波历史、原图、路径、预测消息和原生七项 critic 分数。两种输出共享**完全相同**的分数与 softmax 权重：

1. `mixed`：如前轮诊断，对原采样控制求加权均值，再限幅并执行最终 Savitzky–Golay 滤波。
2. `aligned`：先对每条控制独立限幅、滤波，并在该轨迹上评分；直接对这些已评分控制求加权均值，不再二次滤波。

两种输出都用同一原生 raw local costmap 的 CostCritic 碰撞检查器验证静态图；未来 Gazebo 箱体只用于输出完成后的 3 s 开环间隙。原生检查器逐组顺序运行，没有新编译；镜像固定为 `sha256:0aa16ce3fd9c78d5d3bdab4873a51d077ea9dc637578091c860ad2b326d1b0a6`。

所有六条输出的 padded footprint 与真实移动箱体也保持正间隙；周期 147 对齐聚合后的 padded 最小间隙为 **0.03315 m**。周期 147 两种完整序列的最大单分量差达 **0.1136**，因此不能只看当前返回命令接近就断言后续控制序列等价。周期 162 的两种完整序列逐浮点值相同。周期 263 对齐聚合的 3 s 终点距目标位置约 **0.3840 m**，比 `mixed` 的 **0.3779 m** 更远，仍不如原控制约 **0.3585 m**。这条候选的目标问题不能归因于最终滤波与候选滤波的差别。

[准备结果、原生静态检查夹具和掩码、最终摘要](evidence/filtered_aggregate_alignment_20260928/summary.json)保存三个源周期、profile、Gazebo 真值、标准分数、预测分数、静态夹具及原生可执行文件的 SHA256。原始归档是 `navfn_probe_20260924_01/candidate_navfn_1` 的周期 147/162，以及 `rank_phase4_20260924_02/candidate_navfn_1` 的周期 263。周期 147/263 的七项分数来自[跨周期证据](evidence/filtered_cross_cycle_native_20260928/summary.json)，周期 162 的分数来自[17 组全项证据](evidence/filtered_all_critic_20260928/summary.json)。

`aligned` 是离线输出表述对照，不等于完整 Nav2 运行控制器：MPPI 正则仍取原始采样噪声，候选预测轨迹按当前实测速度作首步传播，而这里 3 s 输出评估直接积分控制序列。未校准的中心分布和跨周期闭环反馈仍是独立问题。此证据只排除这三个输入上“改聚合表述即可同时解决避障和到点”的解释，**不支持把实验规则部署**。
